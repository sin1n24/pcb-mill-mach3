# pcb-mill-mach3

小型 CNC（HAKU）と Mach3 で、紙フェノールの片面基板を φ0.5 エンドミル1本で切削したときのノウハウと道具です。
配線データから `.ncd` を作る `pcb_gcode.py` と、削る前に `.ncd` を検査する `ncd_check.py`、Claude Code 用のスキルが入っています。

実際にかわロボ用の制御基板を削って失敗した内容をもとにしています。機種や設定が違えば結果も変わるので、参考値として使い、初回は端材で試してください。

## はまったことと対策

| 症状 | 原因 | 対策 |
|---|---|---|
| NCVC で X0 / Y0 へまっすぐ向かう線が出る | `Y10` のように小数点なしで出力していた。0.001mm 単位と解釈されて Y=0.010mm へ動く | 座標は必ず小数点付きで出力する（`Y10.000`） |
| プログラムが途中で止まる | `( )` のコメント行で止まった | コメントを1行も入れない |
| 一時停止のあと流れが止まる | `M0` は再開操作を待つ | `M0` を使わず、工程ごとにファイルを分ける |
| NCVC でファイルが開けない | 拡張子が `.nc` だった | 拡張子を `.ncd` にする |
| 基板の一部で絶縁溝が銅を切れない | 基板の傾き・反りに対して、切り込みが浅かった（Z-0.10 は上半分が切れ残り、Z-0.15 は手調整が必要だった） | 平らに固定する。深さは Z-0.20 を目安にする |
| 基板を外すときに銅箔が部分的に剥がれる | 外形のタブを切らずに、むしり取った | タブがあることを忘れず、ニッパやカッターで切ってから外す |
| 捨て板を削り過ぎた | 板厚を確かめず 1.6mm 前提で計算した（実物は 1.0mm） | 板厚をノギスで測って指定する（`pcb_gcode.py` では必須の引数） |
| モジュールが基板に入らない | SMD 版のフットプリントの寸法を、ピンヘッダ付きの版に使った（17.5mm と 15.24mm） | 実物の版の寸法図を見て、ノギスで実測してから削る |

## 基板データの作り方で気をつけること

切削で作る片面基板に特有の話です。

- **絶縁は1パスで足りた**。溝幅は工具径の 0.5mm。切削量が少ないほど早く、工具も傷みにくい。
- **GND は配線せず、残った銅箔をベタにする**。GND パッドはサーマルにする。
- **1点だけでつながる銅箔を作らない**。本体のベタに出られない銅箔は、スポークを外して浮かせる。アンテナになってノイズを拾うのを避けるため。
- **GND パッドを外形に寄せない**。ベタとつながる幅がなくなる。
- **渡れない配線はジャンパにする**。空中配線ではなく、専用の穴を2つ設ける。
- **実装面と切削面は左右が逆**。シルクがないので、穴の横に名前を書いた図を両面ぶん用意すると組み立てで迷わない。

## 手順

![切削中の様子](docs/cutting.jpg)

1. 板厚をノギスで測る。部品のピン間隔も実物で確かめる。
2. `.ncd` を作る。

   ```
   pip install shapely matplotlib
   python tools/pcb_gcode.py layout.json out --thickness 1.0
   ```

3. 削る前に検査する。問題があれば理由を表示して終了コード 1 を返す。

   ```
   python tools/ncd_check.py out/*.ncd --thickness 1.0 --width 30 --height 20
   ```

4. NCVC で経路を目で確かめる（`toolpath_preview.png` も出力される）。
5. 捨て板を面出しして、基板を平らに固定する。銅箔面を上にする。
6. 原点を合わせる。**X0Y0 は銅箔面を上にしたときの基板の左下、Z0 は銅箔の表面**。
7. `01_isolation.ncd` だけを流して、溝が全面で銅を切っているか確かめる。切れ残りがあれば、原点を変えずに `--iso-z` を深くして流し直す。
8. `02_holes.ncd` → `03_outline.ncd` の順に流す。
9. **外形のタブ（4辺の中央）をニッパやカッターで切ってから基板を外す**。むしると銅箔が剥がれる。

`00_all_in_one.ncd` は3工程を止めずに続けたものです。絶縁の仕上がりを確認できないので、慣れるまでは使わないほうが安全です。

## 切削条件

`pcb_gcode.py` の既定値です。すべて引数で変えられます。

| 項目 | 既定値 | 引数 |
|---|---|---|
| 工具 | φ0.5 フラットエンドミル | `--tool` |
| 絶縁の深さ / 送り | Z-0.20 / F200 | `--iso-z` `--iso-f` |
| 穴の送り | F120 | `--hole-f` |
| 外形の送り | F150 | `--out-f` |
| 1回の切り込み（穴・外形） | 0.35mm | `--step` |
| 切り込みの送り | F60 | `--plunge-f` |
| 貫通で板厚を超える量 | 0.15mm | `--through` |
| 外形タブの残し厚 | 0.5mm | `--tab` |
| 主軸 | S10000 | `--spindle` |

### 確かめた範囲

- **確かめたこと**: F200 / F120 / F150 で 1.0mm 板の絶縁・穴・外形を削り、基板として加工できた。板厚 1.0mm で Z-1.15 まで切る貫通の仕上がりは良好。モジュール（列間隔 15.24mm）も挿さった。
- **絶縁の深さ**: Z-0.10 は上半分が切れ残り、Z-0.15 は手調整で切り抜けた。Z-0.20 なら行けそうという見込みで、**Z-0.20 ではまだ削っていない**。
- **主軸**: この機械の主軸モーターの銘板は 4300 r/min。`S10000` は指令値で、実際の回転数ではない可能性がある。
- **参考**: 同じ機械で以前に使った別のデータ（EAGLE 出力）は Z-0.075 / F300 / S6000 でした。

## `layout.json` の形式

座標は実装面（部品を挿す面）から見た mm で、原点は基板の左下です。

```json
{
  "W": 30.0, "H": 20.0,
  "pads": [
    {"ref": "J1", "num": "1", "x": 5.0, "y": 15.0, "net": "SIG", "shape": ["C", 1.9], "hole": ["R", 1.0]},
    {"ref": "J2", "num": "3", "x": 22.0, "y": 5.0, "net": "GND", "shape": ["O", 2.6, 1.8], "hole": ["S", 1.0, 1.6]}
  ],
  "tracks": [{"net": "SIG", "w": 0.6, "pts": [[5.0, 15.0], [22.0, 15.0]]}],
  "mholes": [{"x": 27.0, "y": 3.0, "d": 3.2}]
}
```

- `shape`: `["C", 直径]` は丸、`["O", 幅, 高さ]` は横長の小判形。
- `hole`: `["R", 直径]` は丸穴、`["S", 幅, 長さ]` は X 方向の長穴。
- `net` が `GND` のパッドは配線せず、サーマルで周りのベタにつなぐ。
- `mholes`: 取付穴（任意）。

配線は別のツールで用意します。GND ピン同士が部品の内部でつながっている場合は `--tied U1` で指定すると、GND のつながりの判定に反映されます。

例は `examples/simple/` にあります。この例は実際には削っていません。
